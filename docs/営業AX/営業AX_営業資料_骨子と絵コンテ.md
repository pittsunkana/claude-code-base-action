# 営業AX 営業資料 骨子と絵コンテ

> お客さん向けの営業資料。「あなたの課題はこう解決できます」というストーリー。
> 表紙には「研修」ではなく「営業組織のAI変革支援」を掲げる。研修はその中のサービスの一つ。

## P2: こんなお悩みありませんか？

```
┌─────────────────────────────────┐
│  こんなお悩みありませんか？      │
│                                 │
│  ┌────────┐  ┌────────┐        │
│  │ PoCは   │  │ 効率化は│        │
│  │ やったが │  │ 進んだが│        │
│  │ 成果が  │  │ 売上には│        │
│  │ 限定的  │  │ 未直結  │        │
│  └────────┘  └────────┘        │
│                                 │
│  ┌────────┐  ┌────────┐        │
│  │ コンサル │  │ AI活用の│        │
│  │ に頼んだ │  │ 業務で  │        │
│  │ が実行に │  │ どこから│        │
│  │ 至らず  │  │ 手を付け│        │
│  └────────┘  │ れば… │        │
│               └────────┘        │
└─────────────────────────────────┘
```

**4つのペイン**:
1. いくつかPoCはしたが、事業成果が生み出せていない
2. ちょっとした効率化はAIで進んだが、売上成果の向上まではつながっていない
3. 高いお金を払ってコンサルに依頼したが、実際の業務変革には至っていない
4. AI活用の業務でどこから手を付けていいかわからない

│  │ 工数削減  │  │ 業務の強化│    │
│  │           │  │           │    │
│  │ 議事録    │  │ 商談の質  │    │

## 構成のポイントまとめ

| 区間 | ページ | 意図 |
|---|---|---|
| 共感パート | P2-5 | お客さんのペインに寄り添う。「わかってくれてる」感を作る |
| 視点転換パート | P6-8 | 2つの変革軸、フェーズマップ、DX→AXで視座を上げる。「こう整理すればいいのか」 |
| 商品パート | P9-11 | フェーズに合わせた3段階のサービスを提示。「研修で終わらない」が差別化 |
| クロージング | P12-13 | 信頼性 + 行動喚起 |
