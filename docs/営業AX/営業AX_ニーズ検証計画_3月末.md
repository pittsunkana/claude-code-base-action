# 営業AX ニーズ検証計画（3月末）

> 目的: 営業AXにニーズがあること自体を証明する
> 期限: 3月末
> 前提: KPI「3月末までに1社 1,000万円PoC受注」（CEO議論より）

---

## 「ニーズがある」の証明レベル

| レベル | 証拠 | 強さ |
|---|---|---|
| A | 受注（お金が動いた） | 最強 |
| B | 稟議・発注意思の表明 | かなり強い |
| C | 有料ワークショップへの申込 | 強い |
| D | 「やりたい」の口頭合意・提案依頼 | そこそこ |
| E | 研修/セミナーへの集客数・反応 | 弱いが量で補える |

**3月末で現実的に狙えるのはB〜Cが1-2社 + Eの実績。**

## 2. 入り口商品で「数」を作る（今〜3月中旬）

ニーズの証明 = 1社の受注だけだと「たまたま」と言われる。**数の証拠**も並行で作る。

**一番軽いのは「無料の営業AI壁打ちセッション（30分）」を5-10社やる**こと。

- 骨子のP2-P6あたりの内容を使って30分で話す
- 「御社は今どのフェーズですか？」をリアルにヒアリング
- 終わった後に「次のステップとしてワークショップいかがですか」と提案

これで得られるもの:
- 「10社中8社が課題認識フェーズにいた」などの定量データ
- 「5社からワークショップの見積依頼が来た」という引き合い数
- ヒアリング内容自体が営業資料のブラッシュアップに使える

## 補足: 営業資料の作り込みについて

営業資料は壁打ちを回しながら同時並行で磨くのが効率的。最初から完璧な資料を作るより、5社と話した後の資料の方が圧倒的に刺さる。
