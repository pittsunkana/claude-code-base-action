# Kana Slack Style スキル

## 概要

かなさん（igarashi-kana）のSlack投稿の文体・構成を再現するスキル。
方針・戦略の共有系の投稿を作成する際に使用する。

## 文体の特徴

### トーン
- 「ですます」と「だ・である」が混在する社内チャットらしいカジュアルさ
- 断定と柔らかい表現のバランス
- 事実ベースで語る（「8割ファクト」のように根拠を示す）

### 構成パーツ（必要なものだけ組み合わせる）

投稿タイプに応じて以下のパーツから必要なものだけ選ぶ。毎回全部使わない。

1. **文脈設定**（ほぼ必ず使う）
   - 冒頭1行で「誰の何に対する投稿か」を明示
   - 例: 「〇〇の補足です。」「〇〇について共有です。」

2. **誤解潰し**（方針転換・びっくりさせそうな時だけ）
   - 「〜という話ではなく」で先に誤解を潰す
   - 不要な場面では使わない

3. **太字見出し + 地の文**
   - 太字は見出し的に使う：「**現状認識（相対してきた企業の8割がこう）：**」
   - 説明文はベタ書きで繋げる
   - 箇条書きは要点だけ短く

4. **→ アクション**（進め方がある時だけ）
   - 「→」で始めてテンポよく並べる
   - アクションがない投稿では使わない

5. **締め**
   - 「という〇〇の共有です。」のように投稿の性質を一言で示す
   - 短い投稿なら省略してもOK

### 投稿タイプ別の使い分け

| タイプ | 使うパーツ | 例 |
|---|---|---|
| 短い気づき共有 | 文脈設定 + 地の文 | 「〇〇さんと話して気づいたこと。〜〜だった。」 |
| 方針転換の説明 | 文脈設定 + 誤解潰し + 太字見出し + →アクション + 締め | フルセット |
| ファクト共有 | 文脈設定 + 太字見出し + 地の文 | 見出しで整理して事実を並べる |
| 相談・壁打ち | 文脈設定 + 地の文 + 問いかけ | 「〜〜なんだけど、どう思いますか？」 |

### 避けること
- 毎回同じ構成にならないようにする
- 過度に丁寧な文体（社外メール調）
- 絵文字の多用
- 箇条書きだけの投稿（地の文で文脈を繋ぐ）
